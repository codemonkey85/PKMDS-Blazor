PKMDS: Pokémon Save Editor for Web

Your browser cannot run this version of PKMDS

PKMDS needs browser features that are unavailable or disabled in this browser.

Update to the latest stable Chrome, Edge, Firefox, or Safari. The current runtime requires WebAssembly exception handling, introduced in Chrome 137, Firefox 131, and Safari 18.4. These are feature requirements, not a guarantee that every PKMDS feature has been tested on those exact versions.

On iPhone or iPad, update iOS or iPadOS to 18.4 or later. If your device cannot install that update, use a supported device. Installing a different browser that uses the same system browser engine will not add the missing feature.

See the browser support policy for requirements and validation limits.

Your local save backups and Pokémon Bank have not been removed. They belong to this browser profile and do not automatically appear in another browser, private window, or device. Keep this profile if you need to recover them.

Loading on a supported browser but still not working?

A stale service worker cache can prevent the app from starting after an update. Try these steps — they leave your save backups and Bank storage untouched:

  1. Hard refresh — Ctrl+Shift+R (Windows/Linux/ChromeOS) or ⌘⇧R (Mac). Usually enough.
  2. Unregister the service worker — open DevTools (F12), go to Application → Service Workers, and click Unregister next to the PKMDS entry. Reload the page.
    Do not use "Clear site data" — that also wipes your local backups and Bank.
  3. Incognito / private window — try a fresh session to check whether the problem is specific to your regular profile. Existing backups and Bank will not appear there.

If none of those help, please open an issue and describe what you see (stuck spinner, error bar, or this page).
